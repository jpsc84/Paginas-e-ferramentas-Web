1. Antes de começar: o que é um comando?

Verificação em 6 de outubro de 2026. Este guia cobre ChatGPT na web e no desktop, Work e, quando indicado, Codex. As interfaces não têm listas idênticas. Plano, região, versão, permissões e configuração da organização podem mudar o acesso. Os exemplos são sugestões autorais, não garantias de execução.

Orientação

Comando, recurso ou prompt?

O que faz: Ajuda a escolher a forma correta de pedir uma tarefa.

Como usar: Comando real: escolha no menu ao digitar /. Recurso: selecione uma função disponível. Prompt: escreva o resultado que deseja. Menções @ selecionam contexto ou ferramentas; $ pode invocar skills instaladas.

Crie um resumo de uma página do arquivo anexado, com três conclusões e dúvidas pendentes.

Limitações: Escrever o nome de uma função não instala uma ferramenta nem concede acesso à conta.

11. Um modelo de prompt avançado

Use objetivo + contexto + entradas + restrições + entrega + verificação. Peça fatos e hipóteses separados. Se houver uma lacuna essencial, permita uma pergunta objetiva. Para revisões, diga o que deve permanecer e altere uma dimensão de cada vez.

Prompt de texto

Briefing reutilizável

O que faz: Torna o pedido concreto e verificável.

Como usar: Substitua os campos entre colchetes e anexe os materiais.

Objetivo: [resultado]. Público: [quem usará]. Fontes: [arquivos/links]. Preserve: [fatos e elementos]. Altere: [escopo]. Entregue: [formato e extensão]. Verifique: [critérios]. Separe fatos, hipóteses e lacunas; pergunte se faltar algo essencial.

Limitações: Um bom prompt não remove limites de ferramentas nem garante exatidão. Revise números, fontes e o arquivo entregue.
